# AI tool icon sources

- ChatGPT and Codex: OpenAI mark from Simple Icons v13.21.0, https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/openai.svg. The parent-brand mark is shared, with separate labels and colors.
- Gemini: https://github.com/simple-icons/simple-icons/blob/develop/icons/googlegemini.svg.
- Claude Code: Claude mark, https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg.
- Google Antigravity: official favicon, https://antigravity.google/favicon.svg.
- Subagent workflows: original branching workflow diagram; this is a workflow symbol, not a product logo.

Brand marks belong to their respective owners. White backgrounds and display colors were added to the monochrome marks for readability.
