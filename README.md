# Okan Kaya — Personal Portfolio

An English-language mathematics, data science, and bioinformatics portfolio with a One Piece inspired visual theme.

Live site: https://okankaya07.github.io/

## Features

- Responsive layouts, keyboard navigation, and reduced-motion support.
- Six projects linked to their real-data source repository.
- Grand Line, Golden Hour, and Night Voyage background presets.
- Custom PNG/JPG/WebP backgrounds (up to 8 MB), saved locally in the visitor's browser. Images are never uploaded to a server.
- No analytics, tracking scripts, external fonts, or build dependencies.

## Editing and preview

Edit `index.html` for biography and education, `app.js` for project cards and scene controls, and `style.css` for styling.

Run `python -m http.server 8765` in this folder, then visit http://localhost:8765/. GitHub Pages serves the main branch from the repository root.
